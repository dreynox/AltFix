# AltFix

**AltFix finds the images in your documentation that have no alt text (or alt text that says nothing), describes them with a local open-weight vision model, and edits _only_ the alt text.** It reads Markdown, MDX, HTML and reStructuredText, produces a unified diff you can review line by line, and never sends a single byte of your repository anywhere except the model server running on your own machine.

Accessibility for screen-reader users is not a nice-to-have, but writing good alt text for every diagram, chart and screenshot in a large repository does not scale. Cloud APIs solve it by sending your docs to a third party. AltFix solves it locally: an open-weight vision model (Qwen3.5-9B, Apache 2.0) served by [LM Studio](https://lmstudio.ai) on your own hardware, driven by the surrounding text so the description fits the page it lives on.

---

## Quickstart

Three commands, from a clean checkout to a reviewable patch:

```bash
pip install -e .                 # 1. install AltFix
altfix scan .                    # 2. see which images need alt text
altfix fix . --dry-run           # 3. preview the patch (add --apply to write it)
```

`altfix fix . --apply` writes the changes and prints the diff. `altfix pr . --apply` opens a pull request for them.

To use your own model server, set the endpoint and model id:

```bash
export ALTFIX_BASE_URL=http://localhost:1234/v1
export ALTFIX_MODEL=qwen3.5-9b
```

## What AltFix does

| Stage | What happens |
| --- | --- |
| **Scan** | Finds images in `.md`, `.mdx`, `.rst` and `.html` files: Markdown inline `![alt](src)`, reference `![alt][label]`, HTML `<img>` (including inside `<picture>`) and RST `.. image::` / `.. figure::` directives. Content inside fenced code blocks, `<pre>`/`<code>` and RST literal blocks is skipped. |
| **Classify** | A rule-based pass (no model) sorts every image into `missing`, `low_quality`, `ok` or `decorative`. Badges and spacers are left alone. |
| **Describe** | The local model receives the image plus the surrounding context - the nearest heading, the paragraphs before and after, any caption and the enclosing link text - and is asked for one objective line of at most 125 characters. |
| **Check** | Deterministic checks strip `<think>` blocks, quotes, markdown and filler phrases such as "Image of", enforce the character budget, and reject descriptions that merely echo the file name. A failing answer is retried once with a stricter prompt, and is then marked *needs review* instead of being written. |
| **Patch** | Each edit is applied to an exact character span, so the diff touches the alt text and nothing else. Running it twice changes nothing the second time. |

There is no second model acting as a judge and no LLM scoring of the output: every quality rule is a line of Python you can read.

To rate the descriptions yourself:

```bash
python eval/rate.py export    # writes eval/ratings.csv with 30 random samples

python eval/rate.py score     # prints the mean
```

## The model

| | |
| --- | --- |
| **Model** | [`Qwen/Qwen3.5-9B`](https://huggingface.co/Qwen/Qwen3.5-9B) (multimodal, Image-Text-to-Text) |
| **License** | [Apache 2.0](https://huggingface.co/Qwen/Qwen3.5-9B/blob/main/LICENSE) |
| **GGUF build** | [`lmstudio-community/Qwen3.5-9B-GGUF`](https://huggingface.co/lmstudio-community/Qwen3.5-9B-GGUF), built with llama.cpp `b8185` |
| **Quantization** | `Q4_K_M` (weights) with the `mmproj-Qwen3.5-9B-BF16.gguf` vision projector |
| **Runtime** | [LM Studio](https://lmstudio.ai) local server, OpenAI-compatible API at `http://localhost:1234/v1` |

Load the model in LM Studio (or with `lms load qwen/qwen3.5-9b`) and start its local server. AltFix talks to it over the standard `/v1/chat/completions` endpoint and sends images as base64 data URLs.

Everything is configurable:

| Variable | Default | Meaning |
| --- | --- | --- |
| `ALTFIX_BASE_URL` | `http://localhost:1234/v1` | Model server base URL |
| `ALTFIX_MODEL` | `qwen3.5-9b` | Model id to request |
| `ALTFIX_QUANT` | *(empty)* | Quantization label, recorded in `results/results.json` |
| `ALTFIX_TEMPERATURE` | `0.2` | Sampling temperature |
| `ALTFIX_SEED` | `42` | Sampling seed |
| `ALTFIX_MAX_TOKENS` | `512` | Response token budget |
| `ALTFIX_MAX_IMAGE_DIM` | `1024` | Longest edge after downscaling |
| `ALTFIX_PROMPT_VERSION` | `v1` | Prompt version, part of the cache key |
| `ALTFIX_REASONING_EFFORT` | `none` | Reasoning budget for thinking models |
| `ALTFIX_CACHE_DIR` | `.altfix-cache` | Where descriptions are cached |

The same values can live in an `altfix.toml` file (`[altfix]` section) next to your project.

### Privacy

**Everything runs locally.** The only network request AltFix makes is to the model server you configure, on your own machine. No image, no document text and no alt text is sent to a cloud API, a telemetry service or anyone else. The description cache is a plain directory of JSON files on your disk. The image itself is downscaled to at most 1024px and base64-encoded into the request body - it never touches the filesystem outside the cache.

---

## How the cache works

The cache key is a hash of the model id, the prompt version, the image bytes and the surrounding context. Change any of them and the description is regenerated; change none of them and the cached answer is reused. Every cached record stores the model id and prompt version next to the description, so a stale entry can never be mistaken for a fresh one.

```bash
altfix fix . --no-cache    # ignore the cache entirely
```

## Commands

| Command | What it does |
| --- | --- |
| `altfix scan PATH` | List every image with missing or low quality alt text. `--json` for machine readable output. |
| `altfix fix PATH --dry-run` | Describe the images and show the diff without writing anything (the default). |
| `altfix fix PATH --apply` | Write the changes. |
| `altfix pr PATH --apply` | Create a branch, commit and open a pull request with `gh`, or print the exact manual steps. |
| `altfix review PATH` | Walk through each proposal and accept, edit or skip it before writing. |
| `altfix demo` | Run the whole thing on the bundled sample repository. |
| `altfix model-info` | Show the configured backend and whether it is reachable. |

## What we built vs. what we reused

**Built:** the scanner (a format-aware parser for Markdown, HTML and RST that records the exact character span of every alt text region), the rule-based classifier, the quality checks and their retry logic, the span-based patcher with its escaping rules, the context-aware prompt, the cache with its four-part key, the CLI, the evaluation harness with hand-labelled ground truth, the rating sheet, and the synthetic fixture images.

**Reused:** the model itself, [Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B) (Apache 2.0) and its GGUF conversion by [lmstudio-community](https://huggingface.co/lmstudio-community/Qwen3.5-9B-GGUF); [LM Studio](https://lmstudio.ai) as the local runtime and its OpenAI-compatible server; [Pillow](https://python-pillow.org/) for image resizing; [httpx](https://www.python-httpx.org/), [Typer](https://typer.tiangolo.com/) and [Rich](https://rich.readthedocs.io/) for the HTTP client and terminal output; [pytest](https://pytest.org/) for the test suite. No web UI, no cloud API, no LangChain, no heavyweight orchestration framework.

## Limitations

- **Text inside images is read by the vision model, not an OCR engine.** It is good, not perfect. Small or low-contrast labels are often missed or garbled. If a screenshot depends on a specific string, verify it.
- **Charts are summarised, not read off.** The model describes the trend and the salient values, but exact data-point extraction from a chart is unreliable. AltFix does not attempt to become a data table.
- **Alt text alone is not a full accessibility audit.** A descriptive alt text is necessary but not sufficient: headings, link text, table markup and keyboard order all matter, and AltFix only touches alt attributes.
- **The model must actually be loaded.** If LM Studio has no model loaded, AltFix marks every image *needs review* and changes nothing. It never falls back to a placeholder guess.
- **A wrong description is worse than no description.** AltFix prefers to leave an image alone and flag it for review rather than write something inaccurate.

## How this was built

The code in this repository was written with an AI coding assistant and then reviewed and tested by the team. Every change is covered by the pytest suite in `tests/`, which runs on every push and does not need a model server. The evaluation numbers in `results/` come from real runs against a local model, and the alt text in the demo comes from real model output - nothing in this repository is mocked, hand-written to look like model output, or estimated.
